# lyra-website

The public website for the [Lyra](../lyra) programming language: a **dev blog** plus
**documentation and guides**, built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build).

> **Status:** pre-release, evolving alongside the language.

## Prerequisites

- **Node.js** and **[pnpm](https://pnpm.io)** — use `pnpm`, not `npm`.
- [`tree-sitter-lyra`](../tree-sitter-lyra) checked out as a sibling directory — code blocks
  are highlighted with the real grammar, loaded from the workspace root at build time.

## Commands

From `lyra-website/`:

```bash
pnpm install
pnpm dev              # dev server at http://localhost:4321
pnpm build            # production build → ./dist/
pnpm preview          # preview the production build
pnpm check:snippets   # type-check every lyra code block (needs lyrac)
```

## Structure

```
astro.config.mjs        Astro + Starlight config
src/content.config.ts   content collections (docs + starlight-blog)
src/content/docs/       all pages; file path → route
  blog/  guides/  reference/ (sidebar autogenerated; std-prelude.md is generated)
src/styles/             custom theme
src/assets/             images referenced from Markdown
public/                 static assets
```

Lyra code blocks are highlighted by
[`rehype-tree-sitter`](https://www.npmjs.com/package/rehype-tree-sitter) instead of the
default highlighter. See [`CLAUDE.md`](CLAUDE.md) for more.
