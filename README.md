# lyra-website

The public website for the [Lyra](../lyra) programming language: a **dev blog**
plus **documentation and guides**. Built with [Astro](https://astro.build) and
the [Starlight](https://starlight.astro.build) docs framework.

> **Status:** pre-release, evolving alongside the language.

## Prerequisites

- **Node.js** and **[pnpm](https://pnpm.io)** — this project uses pnpm
  (note `pnpm-lock.yaml`); use `pnpm`, not `npm`.
- A checkout of [`tree-sitter-lyra`](../tree-sitter-lyra) in a sibling directory
  — code blocks are highlighted with the real Lyra grammar (see below), which is
  loaded from the workspace root at build time.

## Commands

Run from `lyra-website/`:

```bash
pnpm install     # install dependencies
pnpm dev         # local dev server at http://localhost:4321
pnpm build       # production build → ./dist/
pnpm preview     # preview the production build locally
pnpm astro ...   # Astro CLI (e.g. `astro add`, `astro check`)
```

## Structure

```
astro.config.mjs          Astro + Starlight config (integrations, sidebar, markdown pipeline)
src/
  content.config.ts       content collections (docs + starlight-blog schema)
  content/docs/           all pages; file path → route
    index.mdx             landing page
    blog/                 dev blog posts
    guides/               guides (incl. guides/types/)
    reference/            reference docs (sidebar autogenerated from this dir)
  styles/                 custom theme
  assets/                 images referenced from Markdown
public/                   static assets served as-is
```

Starlight renders any `.md`/`.mdx` under `src/content/docs/`, mapping each file's
path to a route.

## Lyra code highlighting

Default Markdown syntax highlighting is disabled. Instead,
[`rehype-tree-sitter`](https://www.npmjs.com/package/rehype-tree-sitter)
highlights ` ```lyra ` fenced code blocks using the actual
[`tree-sitter-lyra`](../tree-sitter-lyra) grammar (loaded from the workspace
root in `astro.config.mjs`). Code samples therefore stay in sync with the real
grammar — changes to `tree-sitter-lyra/` affect how snippets render here.

See [`CLAUDE.md`](CLAUDE.md) for more detail.
