---
title: Primitive Types
description: The usual suspects
---

Lyra supports the following primitive types:

```lyra
// Integers
i8 i16 i32 i64
u8 u16 u32 u64

// Floats
f16 f32 f64

// Fixed Point
fixed<8,24> // 8 integer bits, 24 fractional bits

// Char
char

// String
string

// Boolean
bool
```
