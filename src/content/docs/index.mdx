## What is Lyra?

Lyra is a compiled, statically typed programming language, built for games and the tools
around them. It compiles to native code through LLVM, and to Sega Genesis cartridges.

- **No null and no exceptions.** A missing value is a `Maybe`, a failure is a `Result`, and
  the compiler checks that every case is handled.
- **Effects are checked.** `pure`, `det` and `noalloc` are promises about what a function
  may do, and the compiler holds every function it calls to them.
- **Values, not objects.** Structs and sum types are copied unless you ask for sharing, and
  memory is freed by reference counting, with no garbage collector.

New to Lyra? Start with [Getting Started](/learn/getting-started/), or keep the
[cheat sheet](/learn/cheat-sheet/) open while you read some code.
